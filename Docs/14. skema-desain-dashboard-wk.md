## 1. Palet Warna

Gunakan hanya 3 warna dasar berikut di seluruh dashboard WK:
hijau, kuning, putih. Untuk ikon menu, gaya yang disepakati adalah
**duotone gradient** (bukan flat solid) — lihat detail di bawah.

| Nama | Hex | Penggunaan |
|---|---|---|
| Hijau (primary) | `#2E7D32` | Avatar, state aktif navigasi, aksen umum |
| Putih | `#FFFFFF` | Background card/surface |
| Abu-abu teks | `#616161` (grey[600]) | Teks sekunder (jabatan, subtitle) |
| Merah | `Colors.red` | Tombol/aksi Logout saja |

### Gaya ikon Feature Grid — Duotone Gradient (disetujui)

Setiap ikon menu memakai background **lingkaran gradasi** (bukan
warna rata satu tingkat) + shadow tipis berwarna senada, agar
terlihat modern dan tidak generik.

| Elemen | Hijau (menu utama) | Kuning (khusus Laporan) |
|---|---|---|
| Gradasi background | `#E8F5E9 → #A5D6A7` (135°) | `#FFF8E1 → #FFE082` (135°) |
| Warna ikon | `#1B5E20` (hijau tua) | `#E65100` (oranye-kuning tua) |
| Shadow | `#2E7D32` @ 12% opacity, blur 6px | `#F9A825` @ 12% opacity, blur 6px |

**Aturan:** SEMUA ikon menu WK (Absensi, Penjadwalan, Nilai,
Kenaikan Kelas) memakai kombinasi gradasi hijau yang SAMA persis.
HANYA Laporan yang memakai kombinasi kuning. Ikon Laporan sengaja
memakai warna oranye-tua (`#E65100`), bukan kuning terang, karena
kuning terang di atas background kuning muda kontrasnya buruk.

Implementasi Flutter (contoh untuk `Container` ikon di `_FeatureCard`):
```dart
Container(
  width: 48, height: 48,
  decoration: BoxDecoration(
    shape: BoxShape.circle,
    gradient: LinearGradient(
      begin: Alignment.topLeft,
      end: Alignment.bottomRight,
      colors: item.isReport
        ? [const Color(0xFFFFF8E1), const Color(0xFFFFE082)]
        : [const Color(0xFFE8F5E9), const Color(0xFFA5D6A7)],
    ),
    boxShadow: [
      BoxShadow(
        color: (item.isReport ? const Color(0xFFF9A825) : const Color(0xFF2E7D32))
            .withValues(alpha: 0.12),
        blurRadius: 6,
        offset: const Offset(0, 2),
      ),
    ],
  ),
  child: Icon(
    item.icon,
    size: 22,
    color: item.isReport ? const Color(0xFFE65100) : const Color(0xFF1B5E20),
  ),
)
```
Catatan: field `color` tunggal pada `FeatureItem` tidak lagi cukup
untuk gradasi 2 warna — perlu tambahan field (mis. `isReport: bool`
atau `List<Color> gradient`) di class `FeatureItem`, lalu sesuaikan
constructor pemanggilannya di `dashboard_page.dart`.

## 3. Komponen — Header (`_Header` di `dashboard_template.dart`)

**Sekarang:**
- `CircleAvatar` isi huruf inisial nama (mis. "P")
- Teks: `"$greeting, $name"` (mis. "Selamat Malam, Pendi")
- Baris kedua: jabatan
- Baris ketiga: tanggal

**Target:**
- `CircleAvatar` isi **ikon `Icons.person`**, background hijau muda,
  ikon warna hijau solid — bukan huruf inisial
- Teks baris pertama: **nama saja** (hapus kata sapaan "Selamat
  Pagi/Siang/Malam")
- Baris kedua: jabatan (abu-abu, tetap seperti sekarang)
- Tanggal: boleh tetap ditampilkan atau dihilangkan (opsional,
  bukan prioritas)

```
Avatar (48px, bulat, hijau muda + ikon person)
  Nama User (bold, 16px)
  Jabatan (abu-abu, 13px)
```

## 4. Komponen — Feature Grid / "Menu Utama"

**Sekarang (`_FeatureCard`):**
- Card lebar, isi rata kiri-atas
- Ikon kotak rounded (`rounded-lg` style) besar, di pojok kiri-atas
- Judul (bold) + deskripsi 2 baris di bawahnya
- Grid responsif: 2/3/4 kolom tergantung lebar layar

**Target:**
- Card **persegi** (`aspect ratio 1:1`), isi rata **tengah**
- Ikon **bulat penuh** (`shape: BoxShape.circle`), ukuran 48px,
  warna sesuai tabel palet di atas
- **Hanya label singkat** di bawah ikon (rata tengah) — **hapus
  teks deskripsi**
- Grid **3 kolom tetap**, tidak responsif ke 2/4 kolom

```
┌───────────┐
│   ┌───┐   │
│   │ ● │   │  ← ikon bulat, 48px
│   └───┘   │
│  Absensi  │  ← label, center, 12px, medium
└───────────┘
```

Style card: background putih, border tipis abu-abu (`grey[200]`),
radius 16px, tanpa shadow berlebihan (opsional `shadow-sm`).

## 5. Komponen — Bottom Navigation (`dashboard_shell.dart`)

**Status:** struktur SUDAH BENAR, jangan diubah.

- 3 tab tetap: **Dashboard** (ikon grid/dashboard) — **Aktivitas**
  (ikon chart/timeline) — **Profil** (ikon person)
- Tab aktif: warna **hijau** (`#2E7D32`)
- Tab tidak aktif: abu-abu/muted (default)
- Berlaku sama untuk `NavigationBar` (mobile), `NavigationRail`
  (tablet/desktop)

Yang perlu dicek: pastikan warna state aktif konsisten memakai
`Theme.of(context).colorScheme.primary` = hijau, tidak ada warna
lain yang menyelip.

## 6. Komponen — Halaman Profil (`profil_page.dart`)

**Sekarang:**
- Avatar besar (radius 48) isi huruf inisial
- Nama (bold, 22px)
- Pill jabatan (background hijau muda, teks hijau)
- Card "Data Diri" (NIP, nama lengkap, jenis kelamin, jabatan,
  status)
- **Belum ada tombol Logout di halaman ini**

**Target:**
- Avatar: ganti huruf inisial → **ikon `Icons.person`** (sama
  seperti header), ukuran ikon 48px di dalam avatar radius 48
- Nama & pill jabatan: **tetap seperti sekarang**, sudah sesuai
- Card "Data Diri": **tetap seperti sekarang**, tidak diubah
- **Tambahkan tombol "Keluar"** full-width di bawah pill jabatan
  (sebelum Card Data Diri):
  - Style: outline merah, ikon logout + teks "Keluar" warna merah
  - Aksi: reuse logic konfirmasi + logout yang sudah ada di
    `_logout()` milik `dashboard_shell.dart` — jangan duplikasi
    logic baru
  - Perlu pass `VoidCallback onLogout` ke `ProfilPage` lewat
    constructor, dipanggil dari `dashboard_shell.dart`
