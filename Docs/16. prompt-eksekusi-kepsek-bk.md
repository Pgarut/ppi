## Task 1 — Kepala Sekolah/Kepala Madrasah

```
TASK: Terapkan gaya duotone (hijau) untuk Feature Grid dashboard 
Kepala Sekolah/Kepala Madrasah, melanjutkan pola dari WK & Guru 
Mapel/Wali Kelas.

FILE: lib/features/kepala_sekolah/dashboard/dashboard_page_ks.dart

TEMUAN PENTING: dashboard ini hanya punya 2 menu aktif di grid 
(Laporan, Monitoring) — TIDAK ADA menu bersifat "peringatan" seperti 
Pengaduan di role lain, jadi TIDAK PERLU warna kuning sama sekali. 
Kedua menu memakai hijau duotone yang sama.

Catatan: ada file terpisah (jadwal_page_ks.dart, absensi_page_ks.dart, 
nilai_page_ks.dart, rapor_page_ks.dart) yang SUDAH ADA tapi belum 
terhubung ke features map di kepala_sekolah_page.dart. JANGAN 
tambahkan/wire menu baru ke grid dalam task ini — itu di luar scope 
(task terpisah kalau memang belum sengaja dihilangkan).

UBAH dari:
features: const [
  FeatureItem('Laporan', 'laporan', Icons.description_outlined, 'Generate & unduh laporan', Color(0xFF2E7D32)),
  FeatureItem('Monitoring', 'monitoring', Icons.trending_up_outlined, 'Pantau aktivitas sekolah', Color(0xFF43A047)),
],

Menjadi (hapus parameter Color, keduanya default isSecondary: false):
features: const [
  FeatureItem('Laporan', 'laporan', Icons.description_outlined, 'Generate & unduh laporan'),
  FeatureItem('Monitoring', 'monitoring', Icons.trending_up_outlined, 'Pantau aktivitas sekolah'),
],

ATURAN KERJA:
1. Scope HANYA dashboard_page_ks.dart
2. JANGAN ubah _StatGrid (4 stat: Santri Aktif, Asatidz, Kelas, Mapel)
3. JANGAN wire/tambah menu baru ke features map
4. JANGAN ubah KepalaSekolahService atau logic apapun
5. Tunjukkan diff sebelum eksekusi
6. flutter analyze + flutter build web harus sukses

OUTPUT: diff file, konfirmasi build sukses.
```
