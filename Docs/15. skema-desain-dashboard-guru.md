## 4. Perubahan Struktur Kode

### 4.1 Rename field di `FeatureItem` (shared, dampak ke WK juga)

Field yang dibuat khusus untuk WK (`isReport: bool`) di-generalisasi
jadi **`isSecondary: bool`**, supaya bisa dipakai lintas role
(Laporan di WK, Pengaduan di Guru, dst untuk role berikutnya).

```dart
// lib/shared/widgets/dashboard_template.dart
class FeatureItem {
  final String label, key, desc;
  final IconData icon;
  final bool isSecondary; // dulu: isReport
  const FeatureItem(this.label, this.key, this.icon, this.desc, {this.isSecondary = false});
}
```

**Dampak:** semua pemanggilan `FeatureItem(...)` di
`dashboard_page.dart` milik WK yang sebelumnya pakai `isReport:`
harus di-update jadi `isSecondary:`.

### 4.2 List `features` — Guru Mapel/Wali Kelas

File: `lib/features/guru_mapel_wali_kelas/dashboard/dashboard_page.dart`

```dart
features: const [
  FeatureItem('Absensi', 'absensi', Icons.checklist_outlined, 'Input & rekap kehadiran'),
  FeatureItem('Jadwal', 'jadwal', Icons.calendar_month_outlined, 'Lihat jadwal mengajar'),
  FeatureItem('Nilai', 'nilai', Icons.grading_outlined, 'Input & kelola nilai siswa'),
  FeatureItem('Rapor', 'rapor', Icons.assignment_outlined, 'Cetak rapor siswa'),
  FeatureItem('Wali Kelas', 'wali-kelas', Icons.people_outlined, 'Kelola data wali kelas'),
  FeatureItem('Pengaduan', 'pengaduan', Icons.warning_amber_outlined, 'Lapor & pantau pengaduan', isSecondary: true),
],
```
(Parameter `Color` lama dihapus dari constructor karena warna kini
ditentukan otomatis di `_FeatureCard` berdasarkan `isSecondary`.)

### 4.3 Rendering warna di `_FeatureCard` (shared, sudah dari task WK)

```dart
final gradient = item.isSecondary
  ? [const Color(0xFFFFF8E1), const Color(0xFFFFE082)]
  : [const Color(0xFFE8F5E9), const Color(0xFFA5D6A7)];
final iconColor = item.isSecondary ? const Color(0xFFE65100) : const Color(0xFF1B5E20);
final shadowColor = item.isSecondary ? const Color(0xFFF9A825) : const Color(0xFF2E7D32);
```
