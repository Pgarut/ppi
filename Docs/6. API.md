# API Specification
## Sistem Informasi Madrasah Tingkat MA dan MTs

Base URL: `https://api-ppi.example.com` (development: `http://localhost:8787`)

Format: JSON
Auth: Bearer Token (JWT)

---

## 1. Autentikasi

### POST /api/auth/login
Multi-login — validasi role dari tabel `users`.

Request:
```json
{
  "username": "string",
  "password": "string"
}
```

Response (200):
```json
{
  "token": "jwt_token",
  "user": {
    "id": 1,
    "username": "admin",
    "role": "admin",
    "guru_id": null
  }
}
```

### POST /api/auth/logout
Hapus sesi token.

### GET /api/auth/me
Ambil data user yang sedang login.

## 7. Format Respons Umum

### Success
```json
{
  "success": true,
  "data": {},
  "message": "string (opsional)"
}
```

### Error
```json
{
  "success": false,
  "error": {
    "code": "ERROR_CODE",
    "message": "Deskripsi error"
  }
}
```

### Pagination
```json
{
  "success": true,
  "data": [],
  "pagination": {
    "page": 1,
    "per_page": 20,
    "total": 100,
    "total_pages": 5
  }
}
```
