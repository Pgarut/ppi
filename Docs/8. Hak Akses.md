# Hak Akses Modul
## Sistem Informasi Madrasah Tingkat MA dan MTs

Dokumen ini mendefinisikan aksi (`view`, `create`, `edit`, `delete`, `validate`) per modul untuk setiap role. Digunakan untuk mengisi tabel `hak_akses_modul` di database dan acuan frontend/backend.

**Legend:** ✓ = boleh, - = tidak boleh
