## 2. Kepala Sekolah/Kepala Madrasah

### 2.1 Temuan penting

Grid menu dashboard Kamad saat ini **hanya berisi 2 item**:
**Laporan** dan **Monitoring**. Beberapa fitur lain sudah punya
file halaman sendiri (`jadwal_page_ks.dart`, `absensi_page_ks.dart`,
`nilai_page_ks.dart`, `rapor_page_ks.dart`) tapi **belum di-wire**
ke `features` map di `kepala_sekolah_page.dart`. Redesign warna
ini hanya menyentuh 2 menu yang benar-benar tampil — menambah
menu baru ke grid di luar scope task ini.

### 2.2 Layout

```
┌─────────────────────────────────────┐
│ [●] Nama Kamad          🔔          │
│     Kepala Madrasah                 │
│                                     │
│ Ringkasan                          │
│ ┌──────┐┌──────┐┌──────┐┌──────┐   │  ← 4 stat (TIDAK diubah)
│ │Santri││Asatidz││Kelas ││ Mapel │   │
│ └──────┘└──────┘└──────┘└──────┘   │
│                                     │
│ Menu Utama                         │
│ ┌─────┐ ┌─────┐                    │
│ │ (●) │ │ (●) │                    │  ← Hanya 2 item, keduanya
│ │Lapor│ │Monit│                    │     hijau (tanpa kuning)
│ └─────┘ └─────┘                    │
└─────────────────────────────────────┘
```

### 2.3 Warna

| Menu | Ikon | Warna | Alasan |
|---|---|---|---|
| Laporan | `description_outlined` | 🟢 Hijau | Tidak ada menu "peringatan" di role ini — 2 item sama-sama netral, tidak perlu dibedakan |
| Monitoring | `trending_up_outlined` | 🟢 Hijau | idem |

**Catatan konsistensi:** di WK dan Guru BK, "Laporan" biasanya
jadi pengecualian kuning — tapi di Kamad, karena HANYA ada 2 menu
dan tidak ada item bersifat alert/peringatan, keduanya tetap hijau
supaya tidak "memaksakan" pembagian warna yang tidak perlu.

## 3. Guru BK

### 3.1 Layout

```
┌─────────────────────────────────────┐
│ [●] Nama Guru BK        🔔          │
│     Guru BK                         │
│                                     │
│ Ringkasan                          │
│ ┌──────┐┌──────┐┌──────┐┌──────┐   │  ← 4 stat (TIDAK diubah)
│ │Pengdn││Aktif ││Selesai││Konsl │   │
│ └──────┘└──────┘└──────┘└──────┘   │
│                                     │
│ Menu Utama                         │
│ ┌─────┐ ┌─────┐ ┌─────┐            │
│ │ (●) │ │ (●) │ │ (●) │            │  ← Baris 1: Pengaduan,
│ │Pengd│ │Konsl│ │Bakat│            │     Konseling, Bakat&Minat
│ └─────┘ └─────┘ └─────┘            │     (semua hijau)
│ ┌─────┐ ┌─────┐                    │
│ │ (●) │ │ (◆) │                    │  ← Baris 2: Monitoring
│ │Monit│ │Lapor│                    │     (hijau), Laporan (KUNING)
│ └─────┘ └─────┘                    │
└─────────────────────────────────────┘
```

### 3.2 Warna

| Menu | Ikon | Warna | Alasan |
|---|---|---|---|
| Pengaduan | `report_outlined` | 🟢 Hijau | Ini "Pengaduan siswa yang ditangani BK" — pekerjaan rutin BK, BUKAN alert seperti Pengaduan milik Guru Mapel |
| Konseling | `support_agent_outlined` | 🟢 Hijau | Aktivitas rutin |
| Bakat & Minat | `psychology_outlined` | 🟢 Hijau | Aktivitas rutin |
| Monitoring | `trending_up_outlined` | 🟢 Hijau | Aktivitas rutin |
| **Laporan** | `description_outlined` | 🟡 **Kuning** | Konsisten dengan pola WK — "Laporan" selalu jadi pengecualian |

**Peringatan konsistensi penting:** JANGAN tertukar dengan pola
Guru Mapel/Wali Kelas — di sana yang kuning adalah **Pengaduan**
(karena sifatnya darurat/peringatan). Di Guru BK, menu "Pengaduan"
justru adalah pekerjaan inti/rutin BK (menangani pengaduan siswa),
jadi tetap **hijau**. Yang kuning di Guru BK adalah **Laporan**,
mengikuti pola WK.
