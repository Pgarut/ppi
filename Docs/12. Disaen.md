Konsep baru yang saya inginkan

Setelah pengguna login,

Pengguna langsung masuk ke halaman Dashboard.

Dashboard menjadi halaman utama aplikasi.

Dashboard harus menampilkan seluruh fitur utama dalam bentuk Grid Card.

Jangan lagi menampilkan daftar menu vertikal.
