## Rencana Sistem
- Dikembangkan menggunakan Flutter/Dart
- Desain web dan mobile modern: Admin berbasis web saja; Kepala Sekolah, Wakil Kurikulum, Guru Mapel/Wali Kelas, dan Guru BK berbasis web dan mobile/responsif
- Rencana deploy: GitHub, Cloudflare (database menggunakan Cloudflare D1, paket free)
- Rencana pembuatan sistem menggunakan CLI AI coding untuk tahap awal:
  1. Membuat struktur folder
  2. Alur kerja sistem per role dan modul
  3. Database D1 Cloudflare
- Rencana desain:
  1. Multi-login menggunakan split screen
  2. Halaman Admin memakai Mini Sidebar Dashboard
  3. Halaman Kepala Sekolah, Wakil Kurikulum, Guru Mapel/Wali Kelas, dan Guru BK memakai Academic Management Dashboard dengan Mini Sidebar + Topbar + Responsive Layout
- Rencana dokumen lain: menyusul
